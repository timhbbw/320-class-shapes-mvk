# Shapes 🟠

Ziel dieser Übungen ist es das erste Mal mit Klassen zu Arbeiten und grundlegende Konzepte anzuwenden.

- Klassen erweitern und neue erstellen
- Klassenmethoden erstellen nach Anleitung
- Erste Gehversuche mit einem Interface

Beachte, dass diese Übung komplett sinnlos ist, sofern eine IDE mit AI-autocomplete verwendet wird. Daher erst abschalten:

- IntelliJ: `File | Settings | Editor | General | Code Completion | Inline` > "Inline Completion" abschalten.
- VSCode: `Settings | Chat: Disable AI Features`

Alle weiteren Aufgabenstellungen starten mit `src/test/java/ch/bbw/classes/shapes/CircleTest.java`.

Als Theorie kann http://javaseiten.de/oop.html verwendet werden.
